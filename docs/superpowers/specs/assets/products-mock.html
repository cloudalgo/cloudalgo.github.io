01 OrgVitals ↗ Preview Free v1.1.1 · Desktop

A health scanner for Salesforce orgs that runs on your machine, not ours.

Point it at any org you have already authenticated with the Salesforce CLI. It pulls a read-only metadata snapshot and runs 49 scanners across Security, Code Quality, Automation, Tech Debt and Performance, then grades the org A–F and ranks what to fix first. Nothing is written back to Salesforce, and the snapshot never leaves your disk.

How the grade is weighted

  • Security 30%
  • Code quality 20%
  • Automation 20%
  • Tech debt 20%
  • Performance 10%

02 AlgoBridge ↗ Generally available Free — MIT v1.0 · Self-hosted

Your Salesforce data in PostgreSQL, ten seconds behind.

A bidirectional sync engine with trigger-based change detection. Changes move in both directions on a fixed ten-second batch — no polling, no queue to babysit — and every column edit is kept for 31 days so you can answer who changed what. MIT-licensed, runs on your own Docker or ECS, priced at nothing per record.

  • Bidirectional
  • 10-second batches
  • 31-day column diffs
  • Bulk API v2
  • MIT licence

03 Pledgivo ↗ Preview Free to 200 gifts/yr 2GP package · API 67.0

Fundraising that never leaves Salesforce.

The donation form, the payment and the donor record all live in your org, so a gift is a standard Opportunity the instant it is taken — no external platform, no nightly sync, no second permission model to keep in step. Recurring giving, campaigns and ticketed events run on standard objects, which means the reports and sharing rules you already have keep working.

  • Standard objects
  • Stripe Payment Element
  • Recurring & dunning
  • Events & ticketing
  • Passwordless donor portal
  • Multi-Stripe routing

04 InsureAlgo ↗ Generally available Free v1.0.0 · iOS & Android

Every policy you hold, and the date each one lapses.

Vehicle, health, life, home and anything else you want to name, with a countdown to each renewal and reminders ten, five and three days out. There is no account to create and no server to send anything to — policies live on the phone behind a biometric lock, and the only copy that leaves is the one you choose to put in your own iCloud.

  • Offline by default
  • No account
  • Biometric lock
  • Document vault
  • One-tap renewal
